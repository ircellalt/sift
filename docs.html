Guides for running a server

Everything you need to get a Minecraft server online, keep it healthy and understand what you're paying for. Written by the engineers who run the fleet.

Deploy your first server

Choose a plan on the pricing page, pick a region and a name. Your server gets an address of name.sift.gg straight away. Provisioning takes about 47 seconds on average and runs through twelve logged steps.

/whitelist add YourName
/op YourName
/gamemode survival

Point a domain at your server

Create a CNAME record for your domain pointing at your server address. Players connect on the default port 25565, so no SRV record is required unless you use a non-standard port.

If your DNS provider proxies traffic, switch that record to DNS-only. Minecraft uses a custom protocol and proxies can break the handshake.

Choose Paper, Purpur or Fabric

Paper is the default and runs most plugin setups. Purpur adds gameplay options on top of Paper. Fabric and NeoForge are for mod packs. Switching software later keeps your world files.

Using the console

The console shows live output and accepts server commands. Run help for the command list. Commands only work while the server is running.

Backups and restore points

Nightly snapshots are kept off-node. The number you keep depends on your plan, from 2 restore points on Shale to 14 on Obsidian. Restoring a snapshot replaces the current world, so take a manual backup first.

How DDoS filtering works

Filtering runs at the edge of our network, before traffic reaches the node. Attacks are dropped there and your server only receives legitimate connections. Mitigation is included on every plan.

Billing, cycles and refunds

Plans are billed monthly or yearly, in advance. Yearly plans include two months free. You have 32 days from your first order to request a full refund, and nothing is charged until your server is online.

Two-factor authentication

Two-factor is required before you change billing details or remove a server. Set it up from your account settings once you have signed in.
